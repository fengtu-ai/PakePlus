Installation

安装 PakePlus

支持多种安装方式，选择最适合你的方式开始。

使用 npm 或 pnpm 全局安装 PakePlus CLI：

# 使用 npm 全局安装 npm install -g pakeplus # 或使用 pnpm 安装 pnpm add -g pakeplus # 验证安装是否成功 pakeplus --version

通过 Rust 的包管理器 Cargo 安装：

# 使用 Cargo 安装 cargo install pakeplus # 从 GitHub 源码安装最新版 cargo install --git https://github.com/pakeplus/pakeplus # 验证安装 pakeplus --version

直接下载对应平台的预编译二进制文件：

# macOS (Apple Silicon) curl -fsSL https://get.pakeplus.app/darwin-arm64 -o pakeplus chmod +x pakeplus sudo mv pakeplus /usr/local/bin/ # Linux (x86_64) curl -fsSL https://get.pakeplus.app/linux-x64 -o pakeplus chmod +x pakeplus sudo mv pakeplus /usr/local/bin/ # Windows (PowerShell) irm https://get.pakeplus.app/windows-x64.exe -OutFile pakeplus.exe

使用 Docker 容器运行，无需本地安装依赖：

# 拉取镜像 docker pull pakeplus/cli:latest # 运行打包命令 docker run --rm -v $(pwd):/app pakeplus/cli \   pack https://example.com --name my-app # 别名简化使用 alias pakeplus='docker run --rm -v $(pwd):/app pakeplus/cli'
Quick Start

快速使用指南

只需 3 步，将你的网页应用打包为桌面程序。

1

安装 PakePlus

使用你喜欢的包管理器全局安装 PakePlus CLI 工具。推荐使用 npm install -g pakeplus 进行安装。

2

执行打包命令

运行以下命令将网页打包为桌面应用：pakeplus pack https://example.com --name MyApp，根据需要添加自定义参数。

3

运行你的应用

打包完成后，在 ./dist 目录下找到生成的可执行文件，双击即可运行你的桌面应用。

✨

进阶：自定义配置

创建 pakeplus.config.json 配置文件，定制窗口样式、图标、快捷键等高级选项。详见下方配置说明。

Configuration

配置文件说明

通过配置文件实现精细化的应用定制。

配置项 类型 默认值 说明
url string - 要打包的网页地址（必填）
name string auto 应用名称，显示在窗口标题和任务栏
icon string default 应用图标路径，支持 PNG、ICO、ICNS 格式
window.width number 1200 窗口初始宽度（像素）
window.height number 800 窗口初始高度（像素）
window.resizable boolean true 是否允许用户调整窗口大小
window.titleBarStyle string default 标题栏样式：default / hidden / overlay
tray.enabled boolean false 是否启用系统托盘功能
shortcuts object {} 全局快捷键映射，如 {"Ctrl+Shift+C": "copy"}
autoUpdate boolean true 是否启用自动更新检查
FAQ

常见问题

解答你关于 PakePlus 的常见疑问。

PakePlus 和 Electron 有什么区别？ +
PakePlus 基于 Tauri 引擎，使用系统原生 WebView 渲染网页，而 Electron 捆绑了完整的 Chromium。因此 PakePlus 打包后的应用体积更小（通常 3-8MB vs 100MB+）、内存占用更低，但需要系统具备 WebView 运行时。
打包应用需要安装 Rust 环境吗？ +
不需要。PakePlus 提供了预编译的 CLI 二进制文件，可以直接下载使用。只有在使用 Cargo 安装或需要自定义底层功能时，才需要安装 Rust 环境。
支持哪些类型的网页？ +
PakePlus 支持打包任何可访问的网页 URL，包括静态站点、SPA 应用、PWA 以及需要登录认证的 Web 应用。对于需要本地文件系统访问的应用，可以通过插件系统扩展功能。
如何调试打包后的应用？ +
在开发模式下运行 pakeplus dev <url> 可以启用开发者工具和热重载功能。生产模式打包的应用默认不包含调试工具，但可以通过配置文件开启。
打包的应用如何实现自动更新？ +
PakePlus 内置了自动更新检查功能，默认启用。你需要在配置文件中指定更新服务器地址，当新版本发布时，应用会自动提示用户下载并安装更新。
