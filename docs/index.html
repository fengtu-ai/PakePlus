将网页打包成
轻量级桌面应用

PakePlus 是一款命令行工具，让你用一条命令将任何网页打包成 Windows、macOS 和 Linux 桌面应用。体积仅为 Electron 的 1/20。

🚀 快速开始 了解更多 ↓
bash
$ npm install -g pakeplus
$ pakeplus https://example.com --name MyApp
# 🎉 打包完成！输出: dist/MyApp/
核心特性

为什么选择 PakePlus？

专为开发者打造的极致轻量打包体验

⚡

极致轻量

基于 Tauri 构建，打包后的应用仅约 5MB，相比 Electron 动辄 100MB+ 的体积，节省 95% 磁盘空间。

🖥️

跨平台支持

一次打包，同时生成 Windows（.exe/.msi）、macOS（.dmg/.app）和 Linux（.deb/.AppImage）安装包。

🚀

一条命令搞定

无需复杂配置，只需一行命令即可完成打包。支持自定义窗口大小、图标、标题等个性化设置。

🔒

安全可靠

使用系统原生 WebView，内存占用低，安全性高。不捆绑任何第三方运行时，应用运行更稳定。

🎨

深度定制

支持自定义窗口标题栏、托盘菜单、快捷键、单实例模式、代理设置等高级功能。

📦

一键分发

内置自动更新支持，可配置更新服务器地址。支持代码签名，让应用分发更加专业。
